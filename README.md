# Online Job Portal

Project Description

The Online Job Portal is a simple web application that allows users to register, log in, and view available job opportunities. This project is designed to help beginners understand basic web development concepts such as HTML, CSS, and JavaScript.

Features

* User Registration
* User Login
* View Available Jobs
* Simple and user-friendly interface

Technologies Used

* HTML
* CSS
* JavaScript

Project Structure

job-portal
│
├── index.html
├── register.html
├── login.html
├── jobs.html
├── style.css
└── script.js

How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file in your browser or run using Live Server extension.

 Purpose of the Project

This project was developed as a beginner-level web development project to understand:

* Website structure
* Form handling
* Basic JavaScript functionality

Future Improvements

* Add database integration (MySQL)
* Resume upload feature
* Admin panel for managing jobs
* Search and filter jobs
